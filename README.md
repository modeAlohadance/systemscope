# SystemScope

![Build](https://github.com/modeAlohadance/systemscope/actions/workflows/ci.yml/badge.svg)

Нативное приложение для Windows на **C++17 и Win32 API**. Без аккаунта, сети и установки дополнительных пакетов.

## Возможности

- Общая загрузка CPU и использование оперативной памяти.
- Список процессов с PID и фильтром по имени или номеру.
- Доступное место на локальных дисках.
- Автообновление каждые 2 секунды и ручное обновление.
- CSV-снимок ресурсов, дисков и всех процессов (фильтр влияет только на экран).

Первый замер CPU равен нулю: процент вычисляется из разницы двух замеров. Процессы могут завершиться между обновлениями. Приложение только читает показатели Windows и не завершает процессы. Сетевые диски исключены, чтобы не блокировать интерфейс недоступными ресурсами.

## Скачать

[Windows x64 — EXE и контрольная сумма](https://github.com/modeAlohadance/systemscope/releases/latest).
Скачайте `SystemScope.exe` и запустите. Сборка не подписана цифровым сертификатом.

## Сборка из исходников

Windows 10/11, Visual Studio 2022 с компонентом Desktop development with C++, CMake 3.20+.

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
.\build\Release\SystemScope.exe
```

Тесты ядра также собираются на Linux/macOS через CMake; графический интерфейс предназначен для Windows. Статическая C++ runtime включена в EXE.

## Архитектура и проверки

`src/main.cpp` — интерфейс и события; `src/metrics.hpp` — проверяемое ядро; `src/ui.hpp` — Unicode, CSV, диалоги и запись файлов.

GitHub Actions компилирует исходники, запускает CTest и `SystemScope.exe --smoke` с ограничением времени. Проверка запуска автоматически закрывает окно; проверяет получение памяти и списка процессов. Публичные релизы создаются из прошедшего проверки коммита и содержат SHA256SUMS.txt.

## Ограничения и развитие

Интерфейс имеет фиксированный размер. Нет графиков истории и нагрузки отдельных процессов; сбор показателей выполняется в UI-потоке. Отчёты могут содержать имена запущенных программ, поэтому проверяйте CSV перед отправкой.

Предложения и сообщения об ошибках приветствуются в Issues. Лицензия MIT.
